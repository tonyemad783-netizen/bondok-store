# موقع BONDOK — ساعات وإكسسوارات

موقع بسيط جاهز للنشر على GitHub Pages، فيه لوجو بوندوك، وقسم منتجات، وزرار طلب مباشر عبر واتساب.

## قبل النشر — عدّل دول

1. **رقم الواتساب**: في ملف `index.html` دور على `waNumber` و `wa.me/201000000000` وغيّرهم برقمك.
2. **المنتجات**: في نفس الملف، دور على `const products` وغيّر الأسماء والوصف والأسعار، أو ابعتلي صور المنتجات الحقيقية وأنا أستبدل الأيقونات بيها.
3. **السوشيال ميديا**: في قسم "تواصل معنا"، الروابط `#` بجانب IG / FB / TT — حطّ فيها لينكات حساباتك.

## النشر على GitHub Pages (خطوة بخطوة)

1. روح على github.com واعمل حساب لو مفيش عندك.
2. اضغط **New repository** وسمّيه مثلاً `bondok-store` (خليه Public).
3. من صفحة الريبو، اضغط **Add file → Upload files**، وارفع كل الملفات اللي جوه المجلد ده (`index.html` ومجلد `assets`) بنفس الترتيب.
4. اضغط **Commit changes**.
5. روح لـ **Settings → Pages** (في القائمة الجانبية).
6. تحت "Build and deployment"، اختار **Deploy from a branch**، وفي Branch اختار `main` والفولدر `/ (root)`، واضغط **Save**.
7. استنى دقيقة أو اتنين، هيظهرلك لينك الموقع فوق بالشكل ده:
   `https://username.github.io/bondok-store/`

كده الموقع هيبقى شغال ومجاني تمامًا، وأي تعديل تعمله وترفعه تاني هيتحدث تلقائيًا.
